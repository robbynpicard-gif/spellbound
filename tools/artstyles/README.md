# Art-style samples (2026-11-17)

Four complete redraws of the same moment of play in the real game layout
(src/render/layout.ts), to choose the game's look. Not used by the game.

    cd tools/artstyles && python3 style_ink.py && python3 style_manuscript.py && python3 style_glass.py && python3 style_paper.py

- A `style_ink.py` — Ink & Wash Gothic
- B `style_manuscript.py` — Illuminated Manuscript
- C `style_glass.py` — Stained Glass
- D `style_paper.py` — Cut-Paper Shadow Theatre

Output goes to /home/claude/artstyles (change the path at the bottom of each file).

# Multiplayer server (not started)

This folder will hold the Node.js + WebSocket server for Wizard Duel and
Cooperative Tower Defence (Milestone 5).

It is intentionally empty for now. The game must always run without it.
The server will reuse the Phaser-free gameplay rules from `src/` (core,
gameplay, difficulty, spells, modifiers) to validate matches — see
`docs/architecture.md`.
